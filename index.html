Hermes Chat

Свой чат.
На своём сервере.

Веб-интерфейс с двумя режимами: чат отвечает стримом, агент умеет запускать инструменты — читает файлы, смотрит картинки, разбирает ссылки. Работает в локальной сети, без облачных панелей.

Что внутри

Два режима

Обычный чат со стримингом токенов и агент, который планирует и вызывает инструменты.

Агент в песочнице

Запуск через bwrap: /root скрыт, системный корень только для чтения, доступен лишь свой каталог.

Своя история

SQLite на диске сервера: чаты, вложения, аудит — всё под твоим контролем.

Лимиты

Сообщения в минуту, запуски агента в час и суточный бюджет токенов на пользователя.

Вложения

Скрепка, drag&drop и вставка из буфера. Картинки агент смотрит через зрительную модель.

Темы

Светлая и тёмная палитра, переключатель «авто / тёмная / светлая».

Как это собрано

Бэкенд
FastAPI, SSE-стриминг, SQLite, argon2 для паролей
Агент
Hermes CLI внутри bwrap, инструменты: web, file, vision, code
Фронтенд
Один SPA без сборки: HTML, CSS, ванильный JS
Запуск
systemd, один юнит, порт в локальной сети
Модели
любой OpenAI-совместимый провайдер через переменные окружения
